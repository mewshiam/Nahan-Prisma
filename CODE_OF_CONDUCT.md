# Code of conduct

## Our pledge

Everyone participating in this project — issues, PRs, discussions, chats — is expected to keep the space useful and decent. The project serves a community that depends on it; behavior that drives people away hurts real users.

## Our standards

**Encouraged:**

- Assuming good faith, especially across language barriers (English and Persian speakers share this project)
- Precise bug reports and patient triage
- Security-conscious disclosure (see [SECURITY.md](SECURITY.md))

**Not tolerated:**

- Harassment, personal attacks, or discriminatory language
- Publishing other people's subscription links, UUIDs, or server addresses
- DoS-style "testing" against deployments you don't own
- Off-topic evangelizing in issue threads

## Enforcement

Problems get one warning; repeat or severe cases end in a ban from the repository. Report conduct issues by opening a private GitHub vulnerability report (misuse of that channel is fine for conduct reports too — it's the only private inbox this repo has) or by contacting a maintainer directly.
